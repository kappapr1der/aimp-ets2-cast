# AIMP ETS2 Cast

Небольшой DSP-плагин для Windows, который превращает всё, что сейчас играет в AIMP, в локальный MP3-радиопоток для Euro Truck Simulator 2.

## Что он делает

Плейлисты, shuffle, repeat, пауза и переключение треков остаются в AIMP. Плагин получает уже декодированный PCM из DSP-цепочки AIMP, кодирует его в MP3 и отдаёт только на этом компьютере:

```text
http://127.0.0.1:6969/stream
```

Выходной формат: MP3, stereo, 48 kHz, 256 kbps. Перед началом отдачи плагин накапливает около 750 мс корректных MP3-данных, чтобы уменьшить риск заикания на первом подключении.

## Требования

- Windows x64; версия 0.1.1 проверена на Windows 11 24H2 x64, build 26100.
- AIMP x64; проверена версия 5.40.2700.
- `libLAME.dll`, входящая в установленный AIMP; проверена LAME 3.100.
- Свободный локальный порт 6969.

Сборка 0.1.1 только x64. Сторонние DLL в Release не вложены.

## Установка и запуск

1. Скачай `aimp_ets2_cast-0.1.1.aimppack` из GitHub Release.
2. Открой файл и подтверди установку в AIMP.
3. Перезапусти AIMP.
4. В настройках AIMP открой **Плагины** и включи **AIMP ETS2 Cast**.
5. Выбери плагин в DSP/звуковых эффектах, открой его окно и нажми **Start**.
6. Добавь в Internet Radio ETS2 точный адрес:

   ```text
   http://127.0.0.1:6969/stream
   ```

Не добавляй слеш в конце.

- Правильно: `http://127.0.0.1:6969/stream`
- Неправильно: `http://127.0.0.1:6969/stream/`

В версии 0.1.1 путь `/stream/` может вернуть ошибку 404.

## ETS2

Перед ручным изменением `Documents\Euro Truck Simulator 2\live_streams.sii` обязательно сделай резервную копию и сохрани существующие станции. Синтаксис файла зависит от версии игры. Пример одной записи, а не готового полного файла:

```text
stream_data[N]: "http://127.0.0.1:6969/stream|AIMP Local|Local|EN|256|0"
```

Вместо `N` нужен следующий реальный индекс, а счётчик `stream_data` в существующем файле должен соответствовать числу записей.

Версия 0.1.0 подтверждённо работала в ETS2 у реального пользователя, включая смену треков. Версия 0.1.1 сохранила тот же URL и протокол, изменив только стартовую буферизацию; отдельный запуск 0.1.1 в ETS2 на машине релизной сборки не проводился.

## Если что-то не работает

- **Порт 6969 занят:** закрой программу, которая его использует, и снова нажми **Start**.
- **VLC открывает поток, а ETS2 нет:** прежде всего проверь отсутствие лишнего `/` в конце URL.
- **Плагин не виден:** убедись, что AIMP x64, включи плагин в настройках и перезапусти AIMP.
- **Нет звука:** запусти локальный трек, проверь статус **Broadcasting** и открой точный URL во внешнем плеере.

Лог находится здесь:

```text
%LOCALAPPDATA%\AIMP-ETS2-Cast\ets2cast.log
```

Метаданные трека пока не передаются. Сервер намеренно доступен только через `127.0.0.1`.
